<Note>
  É o que mantém a tela do comprador viva enquanto o Pix não cai. A confirmação devolve a cobrança
  `pending`; quem resolve é o webhook do banco, segundos ou minutos depois. O quadro consulta daqui
  até pagar, expirar ou falhar, e emite o evento que você escuta — ver
  [Referência do SDK](/embed/sdk).
</Note>

<Note>
  `paid: true` com `paid_at` em `null` é o caso normal logo depois do pagamento: a data vem no
  webhook e chega um instante depois. Quem decide que acabou é `paid`. Quem libera o produto no seu
  sistema continua sendo o webhook `charge.paid`, e não esta consulta.
</Note>
