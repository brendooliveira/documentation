<Note>
  Endereço fixo e para sempre, sem hash de build — é o único da API escrito à mão no HTML de
  terceiros, e um nome que mudasse a cada versão nossa quebraria o checkout de toda loja. É também o
  único que dispensa autenticação: a chave entra depois, em `Vext(pk)`. Ver
  [Referência do SDK](/embed/sdk).
</Note>

<Tip>
  O cache é curto de propósito: é o nosso botão de emergência, e uma correção no carregador alcança
  as lojas em minutos sem pedir a ninguém que limpe nada. Sirva o script sempre daqui — uma cópia no
  seu CDN congela justamente a versão com o defeito.
</Tip>
