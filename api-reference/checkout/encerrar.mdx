---
title: "Encerrar sessão"
description: "Cancela uma sessão de checkout antes do prazo, quando o carrinho muda."
icon: "circle-x"
openapi: "/api-reference/openapi.yaml POST /v1/checkout_sessions/{code}/expire"
---

<Note>
  Encerrar é o que você chama quando o comprador volta e troca o produto. A sessão antiga seguiria
  cobrável até vencer, e o `client_secret` dela já está no navegador de alguém — um quadro deixado
  aberto numa aba cobraria o carrinho velho.
</Note>

<Note>
  Uma sessão que **já virou venda** responde `422`. Trate esse erro olhando o `charge_id` antes de
  chamá-lo de falha da integração: "cancelei" sobre uma venda que aconteceu é a resposta que faz
  alguém deixar de entregar um produto pago. Para devolver o dinheiro, o caminho é
  [Estornos](/essenciais/estornos).
</Note>
