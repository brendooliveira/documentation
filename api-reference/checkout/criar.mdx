<Warning>
  O `client_secret` aparece **uma vez só**, nesta resposta: guardamos só um hash. Entregue-o ao
  navegador já na requisição que desenha a página. Uma consulta posterior à sessão não o traz de
  volta, e recuperá-lo custa abrir outra sessão — com a venda esperando.
</Warning>
