<NotaIdempotencia />

<Note>
  `items` é **obrigatório**. Mande pelo menos um item. Quem vale é o `amount` da cobrança: se a soma
  de `quantity * amount` não bater com ele, a cobrança sai assim mesmo, com os itens fundidos num só
  pelo valor cheio. Para o comprador ver cada item, faça a soma fechar.
</Note>

<Note>
  A resposta traz `pix.qr_code`, o payload copia-e-cola. A **imagem** do QR não é devolvida: você a
  gera localmente a partir do payload. Ver [Checkout PIX de ponta a ponta](/receitas/checkout-pix).
</Note>
