<Note>
  A grade vem bandeira por bandeira porque a bandeira só é conhecida quando o comprador digita os
  seis primeiros dígitos. Mostre a chave `default` antes disso — ela é o pior caso, então o preço
  nunca sobe depois. Ver [Cobrança no cartão](/essenciais/cartao).
</Note>
