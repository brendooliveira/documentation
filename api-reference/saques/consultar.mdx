<Note>
  Para saber que o saque caiu, o webhook [`withdrawal.paid`](/api-reference/webhooks/withdrawal-paid)
  dispensa consultar em laço. A consulta é o caminho para os desfechos sem evento: `failed`,
  `canceled` e `rejected`. Ver [Saques](/essenciais/saques).
</Note>
